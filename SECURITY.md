Please report security vulnerabilities privately through GitHub's [private vulnerability reporting](https://github.com/MaxRink/jellyfin-plugin-sso/security/advisories/new), not in a public issue. If using LLMs/AI to find the issues, first verify the issue exists manually. Please do not publicly disclose security vulnerabilities until after a stable release for the fix has been released for 30 days.

The latest released version is the only supported version.
